# idop-stock-network

基于 idopNetwork 模型的股票动态网络分析：多层网络重建、构建网络特征、收益率预测与资产定价检验。

> 当前为仓库整理阶段。截至 2026-11-16，已迁入网络、特征、预测、评估和资产定价模块，并跑通合成数据的日频/月频预测与评估。尚未完成正式 1210 日全量运行或独立环境全流程复现；详见 docs 的验证状态。

## 研究内容

本项目研究股票间带方向、带符号的多层网络关系能否提供增量收益率预测信息，并比较传统特征、网络特征及二者结合的模型。现有代码覆盖：
- 利用股票网络每日收盘价构建阶段网络 effects 。
- 从阶段网络 effects 重建逐日带符号权重矩阵。
- 提取拓扑、历史、滞后收益影响和中心性特征。
- LightGBM 日收益率预测，以及独立的自然月收益率预测流程。
- 网络方向性消融和阶段静态收盘价相关网络基准。
- 预测收益率分组、多空组合、风险调整收益、交易成本及市场状态分析。

目前实证数据以科创板为主。

## 方法与时间口径

权重矩阵约定为 `W[t][i,j]` 表示股票 i 对股票 j 的影响，行是来源，列是接收者。重建脚本对分网络及合并后的网络进行列 L1 归一化。

现有对照实验采用 89 个网络特征：79 个拓扑/历史特征、5 个滞后收益影响特征、5 个最终网络中心性特征。当前 R/features 的字段字典和合成测试已核对该数量，正式全量输出仍待验证。

| 流程 | 预测目标 | 训练与预测方式 |
|---|---|---|
| 日收益率 | Date=t 当日的单交易日收益率 | 每个自然月重新训练，逐日预测；特征在上游对齐和滞后 |
| 自然月收益率 | 月初形成组合所对应自然月的复合收益率 | 使用此前完整月份训练，月初预测 |

“按月训练”不等于“预测月收益率”。两条流程的预测文件和评价结果需要分别保存。

## 已有实验记录

现有本地实验说明记录了以下平均日 Rank IC；本次整理没有重新运行或核验这些结果，不能视为发布版复现结果。

| 对照实验 | 特征组合 | Idop 有向网络 | 对照网络 |
|---|---|---:|---:|
| 方向性消融 | 网络因子 | 0.066236 | 0.024759（无向） |
| 方向性消融 | 传统 + 网络 | 0.075058 | 0.029966（无向） |
| 相关网络基准 | 网络因子 | 0.066236 | 0.039627（相关） |
| 相关网络基准 | 传统 + 网络 | 0.075058 | 0.050775（相关） |

记录来源为原项目 `code/outputs/directionality_ablation/README.md` 与 `code/outputs/correlation_network_benchmark/README.md`。网络因子模型的共同样本记录为 501,823 个股票—日期观测，组合模型为 501,866 个观测，均覆盖 907 个交易日。原始结果文件尚未纳入本仓库。

## 重要方法限制

相关网络基准的现有说明明确记录：相关网络与当前 Idop 阶段估计均使用完整阶段数据，分配到阶段早期日期的矩阵包含阶段后续观测。因此，此版本支持同口径的解释性比较，不能直接称为严格实时的网络估计样本外检验。下游特征滞后不能消除网络估计本身的阶段内前视信息。相关基准使用收盘价水平而非收益率计算相关性，也应在解读中注明。

## 数据与环境

现有数据来源目录为国泰安数据集；传统因子构建还依赖本地下载的财务、分析师、交易估值与融资融券文件。原始数据和大型中间矩阵不随此次整理复制。正式公开前应明确数据授权和可分发范围，提供字段说明及获取步骤。

项目使用 R 和 Python，现已提供：

- [requirements.txt](requirements.txt)：固定本机 Python 3.9.6 环境中 7 个直接依赖的版本，包括 LightGBM 的 scikit-learn 接口依赖和读取 XLSX 的 openpyxl；不锁定全部传递依赖。
- [renv.lock](renv.lock)：由 renv 根据本机 R 4.5.1 已安装包生成，记录 127 个包，包含核心 R 依赖及其递归依赖。renv 1.3.1 是本次生成锁文件时使用的工具版本。

覆盖范围是脚本清单中已确认的网络矩阵重建、特征、预测、对照和资产定价流程，以及传统因子候选入口。2026-11-12 已补入阶段网络估计所需依赖；其他历史实验及论文排版工具不在本次依赖范围；这不是整个原研究目录的完整环境快照。

在仓库根目录安装 Python 依赖：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

建议使用与记录一致的 R 4.5.1，在仓库根目录的 R 会话执行：

```r
install.packages("renv", repos = "https://cloud.r-project.org")
renv::restore(lockfile = "renv.lock", prompt = FALSE)
```

锁文件不会安装 R 本身，也不锁定操作系统编译库。已验证当前环境中的 Python 包导入、LightGBM 小样本训练/预测、R 核心包加载和锁文件格式；尚未在全新环境执行完整安装恢复或实验复现。
