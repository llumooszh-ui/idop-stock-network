## 数据契约

| 对象 | 约定 |
|---|---|
| 权重 | W[t][i,j]：行 i 为来源、列 j 为接收者；重建去自环、保留符号、层内列 L1、合并后列 L1 |
| 特征长表 | Date、stock 主键唯一；target_return 为该日小数收益；其余列全部作为数值特征 |
| 正式网络字段 | 89 项：SC 26、NP 20（含 5 中心性）、ND 38、NWR 5；加三个标识/标签列共 92 列 |
| 股票标识 | 所有文件需使用同一名称/代码体系；Python 按字符串保留前导零，不自动映射名称 |
| 收益宽表 | 首列日期，其余列股票，0.01 表示 1%；输入不得混入说明行；各入口编码参数分别配置 |
| 日频预测 | Date=t 是当日目标收益日期；特征应已在上游滞后 |
| 月频预测 | Date 是形成月首交易日；目标是同一自然月复合收益，不是后一个月 |
| 风险因子 | 月度字段与单位见 asset_pricing README；必须显式 factor-units，不推断百分比 |

## 时间和样本衔接

1. features 的主体指标滞后一次；NWR 使用 R[t−1]、W[t−2]，中心性使用前一矩阵日期。预测不再次滞后。主体按股票前一观察值滞后，在重新进入样本时不一定是前一个市场交易日。
2. 日频预测训练数据严格早于该月首个实际预测日；月频使用此前月份。预测和评估默认排除最后观察月，资产定价并不自动共享该排除规则，须对齐范围。
3. 自然月有效收益覆盖率默认 80%；预测标签来自因子表中的日收益，评估和资产定价来自独立收益宽表。数据来源和日历不同会造成标签差异，必须核对。
4. evaluation 每个配对使用共同股票—日期样本；资产定价默认各模型独立样本（per_model），提供 common 选项。两者不同是明确的研究口径，不是接口故障。
5. 完整阶段网络可能含阶段后续信息；下游滞后和共同样本比较不能消除这个限制。

模块的精确参数与文件名见各 README；正式 1210 日检查应在 network/features 层显式设置，不套用到合成示例。
