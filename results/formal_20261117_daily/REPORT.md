## 文件与限制

- 配置快照：config.json；完成状态与实际命令：run_manifest.json。
- prediction/ 下有三模型预测、重要性及各自 manifest；evaluation/ 下有两配对的全部指标、检验及共同样本。
- historical_prediction_comparison.json 保存新旧预测数值比较。
- 使用既有模型参数，未调参；没有修改输入数据。网络无穷特征由既有加载规则转为缺失。
- 完整阶段网络估计的前视限制仍然存在，因此这些结果不能直接表述为严格实时可交易的样本外收益证据。
- 本次没有运行正式月频预测或资产定价；不能据此得出交易成本后的经济收益结论。
- 结果位于被 Git 忽略的 outputs，原始完整输出保留于本地；本目录为发布副本。
